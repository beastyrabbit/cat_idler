# LAI.33A Playwright Scenario Manifest

This manifest defines the replayable Playwright play-test contract for LAI.33A. The original
ten-checkpoint matrix remains the full evidence contract. The shipped executable subset and its
current checkpoint consolidation are recorded additively below.

All scenarios use the exact Portless setup from
[testing-cutover.md](../testing-cutover.md#portless-rusttrunk-setup) and the evidence schema from
[evidence-schema.md](evidence-schema.md). The Playwright layer must operate shipped UI controls
through accessible roles, labels, visible text, pointer/keyboard input, and navigation. It may read
DOM/accessibility state and screenshots, but it must not use DOM/state injection, private endpoint
calls, auth bypass, manufactured inventory or Favor, synthetic snapshots, or undocumented time
skips.

## Global Preconditions

- Commit: full git SHA recorded in `manifest.json`.
- Seed: deterministic LAI.33A fixture seed recorded in `manifest.json`; every checkpoint records the
  current simulation tick.
- Fixture: SQLite fixture with checksum before startup and after restart.
- URLs: named Portless API and browser URLs only; numeric localhost URLs are invalid.
- Sessions: one owning-god browser context for the primary colony; a second authorized browser
  context only for the multi-colony secrecy and diplomacy/trade checkpoints.
- Forbidden values: hidden stock, exact regeneration below effective report level 4, private
  beliefs/plans, auth material, another colony's private state, fabricated inventory/Favor, and
  unbounded errors.
- Cleanup: after each checkpoint, return to a stable route/view and clear transient popovers through
  shipped UI controls only.

## Execution Order

Run checkpoints in this exact order: P00, P01, P02, P03, P04, P05, P06, P07, P08, then P09. The
eight required journeys are P01 through P08; P00 and P09 are mandatory setup/regression checks. A
failure in any checkpoint fails the whole LAI.33A Playwright layer and must still preserve the
artifacts captured up to failure.

## Shipped executable consolidation (2026-07-23)

`tests/browser-playtests/leader-ai-overhaul.spec.cjs` executes the same production contracts in
eight serial tests against the signed fixture. This consolidation does not remove any assertion
from the matrix:

| Executable ID | Matrix coverage |
|---|---|
| P00 | Startup, authentication, current protocol, first authoritative snapshot, console/network checks, and hidden-regeneration scan. |
| P01 | Real plan move-up, move-down, and dismissal controls with exact version lanes and response/snapshot reconciliation. |
| P02 | Standing-order create, edit, and delete through canonical/aliased authoritative IDs. |
| P03 | Shrine pipeline visibility, exact Favor, frontier research purchase, and player-only Divine Boost. |
| P04 | Report-safe cat/anatomy inspection, treatment, and prosthetic fitting with conserved identity. |
| P05 | Two production browser contexts, diplomacy mutation, trade acceptance, isolation, typed response, and refreshed snapshots. |
| P06 | Cave/source Hunt, actual water source, reachable dry bank/work slot, pinned endpoint, and one canonical 3 x 3 Workshop objective with exactly nine cells. |
| P07 | Shipped reload control, current-protocol reconnect, restored authenticated session, and selected-colony preservation. |

Every mutation records the prior snapshot count and waits for the exact action kind, its matching
idempotency response, and a later LAI.24 snapshot. The fixed-canvas coordinates are versioned in
[selector-action-map.md](selector-action-map.md); they operate real Bevy controls only when the
current AccessKit wasm null adapter prevents Chromium from discovering semantic nodes.

The source SQLite fixture is immutable. The launcher verifies its manifest checksum, copies it to a
temporary runtime directory, preserves normal authentication, and optionally freezes ticks only for
the deterministic debug fixture. The server still publishes an immediate snapshot after auth and
after each action, so a frozen clock cannot hide a valid mutation.
